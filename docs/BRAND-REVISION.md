# 공식 HANDSLab 브랜딩 반영

사용자 제공 `0430 HANDSLab LOGO (3) (3).ai`에서 공식 로고 영역을 추출했습니다. 원본은 `assets/brand/HANDSLab-original.ai`에 보존합니다.

- 네이비 #003878, 청록 #0099AD, 흰색을 주요 색상으로 적용했습니다.
- 헤더·푸터에 실제 로고를 넣고 심볼을 파비콘으로 사용합니다.
- 로고를 다시 그리거나 변형하지 않고, 투명 배경의 고해상도 PNG와 SVG를 추출했습니다.
- 히어로를 은은한 청록색 도면 격자와 정사각형 제품 패널로 바꿨습니다.
- 100개 카드 이미지 영역은 모두 1:1 정사각형입니다. 이미지 요소가 프레임 밖으로 나가지 않도록 고정하고 `object-fit: contain`으로 제품 전체를 보존합니다.
- 100개 프레임의 가로·세로 동일 여부와 이미지 경계 포함 여부를 실제 DOM에서 검사했습니다. 모두 통과했습니다.
- 변경 전 데이터·사양·가격·출처는 유지합니다.

`dist/brand.css`는 공식 로고 기반 디자인을 담당합니다. 원본 AI와 SVG는 소스 자산이며 웹 실행본은 가벼운 PNG를 사용합니다.
