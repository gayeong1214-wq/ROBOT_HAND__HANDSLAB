# 벤치마크 조사 기록

조사일: 2026-11-12. 검색 → 원문 확인 → 사용 시나리오 비교 → 기능 요구사항 도출 순서로 진행했다. 검색 결과의 순위는 성능 순위로 사용하지 않았다. 실제 하드웨어 실험은 하지 않았다.

## 조사 질문과 검색
검색어: `robot hand database comparison dexterous hands robot specifications`, `robot hands Shadow Allegro LEAP hand official specifications`.
평가 과업: (1) 특정 모델 찾기 (2) 4지/5지·국가별 좁히기 (3) 여러 모델 비교 (4) 가격 조건 파악 (5) 논문과 제조사 원문으로 이동.
발견 후보: Robo2u, Dexhands, RoboZaps, DexHand Atlas, IEEE Robots Guide, Shadow Robot, LEAP Hand, Allegro Hand, ORCA.
Dexhands는 본문 요청이 시간 초과됐고 ORCA는 읽을 수 있는 본문이 없어 핵심 평가에서 제외했다. 최신 기술 사양은 제조사·연구팀 원문만 검증 근거로 삼고 디렉터리는 UX 비교에만 사용했다.

## 최종 벤치마크 6곳

### 1. IEEE Robots Guide
주소: https://robotsguide.com/
관찰: 이미지 카드, 분야별 카테고리, 검색, 교육 자료와 로봇 소개를 제공한다.
장점(설계 판단): 사진과 짧은 설명으로 탐색 진입이 쉽고 다양한 로봇 분야로 확장하기 좋다.
단점(본 과업 관점): 인기 평가와 넓은 로봇 범주가 연구용 핸드의 정밀 사양 비교보다 앞선다.
채택: 그래픽 카탈로그, 사진 중심 카드, 분야와 국가 필터. 인기 점수는 도입하지 않는다.

### 2. Robo2u Robotic Hands
주소: https://data.robo2u.com/hands
관찰: 모델·제조사 검색과 손가락 수, DoF, 구동, 파지, 중량, 촉각, ROS2, 가격 열을 한 표에 표시한다.
장점: 다수 제품을 같은 열에서 훑기 쉽다.
단점: 넓은 표는 작은 화면에서 읽기 어렵고 n/a 및 서로 다른 가격·측정 조건의 직접 비교에 주의가 필요하다.
채택: 위키형 표, 공통 필터, 선택한 최대 3개 모델만 비교. 원문의 불확실성을 별도 배지로 표시한다.

### 3. Shadow Robot Dexterous Hand Series
주소: https://shadowrobot.com/dexterous-hand-series/
관찰: 제품군 비교표에 actuated DOF, 관절, 무게, 손가락, 센서와 제어율을 구분한다.
장점: 구동축과 총 관절의 차이를 이해하기 쉽고 제품 세대·구성 비교에 유용하다.
단점: 한 제조사 제품군 중심이므로 전세계 탐색에는 여러 사이트를 오가야 한다.
채택: 상세 사양 원문 보존, 세대와 구성 주의, 원문 링크. 단순 숫자 하나로 성능 순위를 만들지 않는다.

### 4. LEAP Hand v1
주소: https://v1.leaphand.com/
관찰: 논문, 코드/API, CAD·URDF, 시뮬레이션 자료, 실험 영상을 연결한다.
장점: 구매 전후의 연구 재현성과 개발 시작에 필요한 자료를 함께 찾을 수 있다.
단점: 연구 프로젝트 단위의 긴 페이지라 여러 상용 제품을 빠르게 비교하기에는 제한된다. 자작 부품비와 판매 키트 가격은 다르다.
채택: 모델별 관련 연구 연결, 자작 부품비 배지, 노션의 세대 동일성 주의사항 보존.

### 5. Allegro Hand
주소: https://www.allegrohand.com/
관찰: Product와 Tech Info 메뉴를 세대별로 구분하고 연구·뉴스·동영상을 제공한다.
장점: 제품 소개와 기술 문서를 목적에 맞게 찾아갈 수 있다.
단점: 여러 세대와 센서 구성이 있어 이름을 생략하면 잘못 비교하기 쉽고 다중 제조사 검색은 지원 범위 밖이다.
채택: 정확한 전체 모델명, 제조사 링크, 연구와 구매 근거 분리.

### 6. ROS 2 Documentation
주소: https://docs.ros.org/en/rolling/
관찰: 튜토리얼, 사용 안내, 개념, 참고 자료를 구분한 기술 문서 구조를 제공한다.
장점: 반복 방문하는 연구자가 필요한 문서로 바로 접근하기 좋다.
단점: 제품 사진과 시장 탐색에 최적화된 카탈로그는 아니다. 버전별 차이도 확인해야 한다.
채택: 위키 상세 페이지, 출처·용어 안내, 깔끔한 문서 탐색. 소프트웨어 지원 여부는 추측하지 않는다.

## 통합 설계
그래픽형은 IEEE의 사진 중심 발견, 위키형은 Robo2u의 표, 상세 정보는 Shadow의 구성 구분과 Allegro의 세대별 문서, 연구 링크는 LEAP, 지식 구조는 ROS 문서의 장점을 결합한다. 흰색 배경과 코발트 블루를 사용하고 검색창을 핵심 조작으로 둔다.

## 데이터 수집과 정합성
사용자 지정 노션 데이터베이스를 fetch하여 스키마를 확인한 뒤 URL 정렬 SQL을 100행 단위로 조회했다. 총 102행 중 제목이 있는 100개를 채택했다. 각 페이지를 다시 fetch하여 첨부 이미지와 연구 자료의 URL을 확인했다. 조사자 개인 식별자는 공개 콘텐츠에 필요하지 않아 내보내지 않았다. 서명된 임시 이미지 URL은 Git에 저장하지 않고 이미지 파일과 안정적인 출처 페이지 링크를 보존한다.

노션에서 가져온 가격·특징은 원본 연구실 자료이며 이번 작업에서 100개 제품을 모두 새로 실측·재견적한 값이 아니다. 추정, 수신 견적, 공개가, 부품비를 구분한다. DoF·관절·구동축은 원문 문장 그대로 보존하며 확인할 수 없는 수치는 생성하지 않는다. 사이트의 2026-11-12는 수집일이며 모든 가격의 확인일이 아니다.

## 이미지 출처와 사용
제품 이미지는 사용자가 지정한 노션 첨부자료에서 수집한다. 모델별 노션 원문·제조사 URL과 로컬 파일 매핑을 함께 저장한다. 저작권은 원 권리자에게 있으며 오픈소스 코드와 별도다. 벤치마크 화면은 조사용 근거로 구분하고 제품 사진처럼 재사용하지 않는다.
