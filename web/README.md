# HANDSLab — A world of robotic hands

전 세계 로봇핸드를 **실제 제품 사진과 사양**으로 탐색하는 정적 웹사이트입니다.
HANDSLab 노션 조사표(「지구상의 로봇핸드 조사」, 99건)를 그대로 옮겼고, 조사표에 없는 값은 채우지 않고 `미확인`으로 표시합니다.

- 사이트 주소: <https://gayeong1214-wq.github.io/ROBOT_HAND_-WEB_/>
- 빌드 도구 없이 `index.html`만 열면 동작합니다.

## 디자인·모션

[Figma 커뮤니티 ‘Moody Dance Studio’](https://www.figma.com/community/file/1498101697479806427/moody-dance-studio)에서 큰 타이포, 히어로 아래 흐르는 띠, 사진 위 큰 인덱스, 고정폭 메타 글꼴을 참고했습니다. 색·배치는 기존 사이트를 유지했습니다.

- 히어로 제목 줄별 등장, 소개·푸터의 스크롤 등장, 갤러리 카드 순차 등장, 카탈로그 숫자 올라가기, 모델명 띠(마우스를 올리면 멈춤)
- `움직임 줄이기` 설정에서는 모든 모션을 끄고 바로 보여 줍니다.

## 데이터 기준

- 원본: `data/source/handslab-public-data.json` — 노션 조사표의 모델 99건(2026-11-18 노션과 대조). 내부 견적·가격·조사자 정보는 넣지 않습니다.
- 노션에서 빠진 `ARTUS Lite`는 사이트에서도 삭제했습니다. 같은 모델이 두 번 들어간 경우는 없습니다.
- 숫자 사양은 `tools/build_data.py`의 `EXTRA`, 나머지 특징은 `data/features.json`에 있습니다. 둘 다 노션 문장에 적힌 내용만 옮깁니다.
- 노션에 없던 칸은 각 제품의 공식 제품 페이지·데이터시트에서 보충했습니다(`data/web_specs.json`, 85개 모델 377칸, 2026-11-18 수집). 칸마다 값을 찾은 주소(`url`)와 페이지 원문(`quote`)을 함께 저장합니다. 노션 값이 있는 칸은 덮어쓰지 않습니다. 표에서는 보충한 칸 오른쪽 위에 작은 민트 점이 찍히고, 상세 화면 출처에 ‘보충 사양’ 링크가 나옵니다. 표 칸에 맞지 않는 사양(전원, IP 등급, 반복정밀도, 크기 등)은 ‘기타 사양’ 열에 둡니다. 리셀러·뉴스·2차 정리 사이트 값은 쓰지 않았습니다.
- 총 DoF는 노션에 `능동 13+수동 3`처럼 두 값이 함께 적힌 경우에만 합으로 채웁니다.
- 능동/총 구분 없이 적힌 자유도는 `표기 DoF`로, 종류가 불분명한 힘은 `기타 힘 표기`로 따로 둡니다.

데이터를 고친 뒤에는 다음 명령으로 사이트용 파일을 다시 만듭니다.

```bash
python3 tools/build_data.py
```

## 사진 출처와 이용 원칙

- 사진은 노션 조사표에 첨부된 제품 사진(모델당 1장)이며, 저작권은 각 제조사·연구기관에 있습니다. 2F-85는 HANDSLab이 따로 받은 Robotiq 제품 사진(`2f-85.png`)으로 바꿨습니다.
- 푸터 아래 줄에 사진 저작권 표기와 삭제 요청 링크를 둡니다.
- 갤러리 카드의 사진 아래와 상세 화면에 **제조사(기관)명과 노션 ‘대표사이트’(제조사 제품 페이지) 링크**를 표시합니다.
- 비영리 연구·교육 목적의 비교 자료로서 출처를 밝혀 인용하는 형태입니다(저작권법 제28조 공표된 저작물의 인용, 제37조 출처의 명시).
- 권리자가 삭제를 요청하면 즉시 내립니다(사이트의 ‘요청하기’ → GitHub Issues).
- 상업적 이용(광고·판매 등)으로 바뀌면 이 근거가 약해지므로, 그때는 제조사 보도자료(Press kit) 이미지를 쓰거나 사용 허락을 받으세요.
